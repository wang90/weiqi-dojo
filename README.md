# 围棋练习盘 · Weiqi Dojo

**[English → README.en.md](README.en.md)**

**[在线使用 → https://wang90.github.io/weiqi-dojo/](https://wang90.github.io/weiqi-dojo/)**

支持 **中文 · English · 日本語 · 한국어** 四种界面语言，点右上角切换。

一个**纯静态、零依赖、可离线使用**的围棋学习网站。打开浏览器就能下棋、做题、打谱，不需要安装任何东西，也不需要服务器。

适合零基础的家长陪孩子入门。

## 功能

### 对弈（首页）
- **人机对战**（默认）或双人对弈，9 / 13 / 19 路自由切换
- **让子**：2～9 子，按标准星位摆放，黑方摆好让子后由白方先走
- **电脑棋力**四档：入门 / 初级 / 中级 / 高级
- **落子实时点评**：每落一子立刻给出这步棋的**优点和缺点**，例如
  - 优点：提掉对方 2 子 / 把自己被打吃的棋救出来了 / 占到了星位
  - 缺点：下在一线，几乎围不到地 / **小心！对方下一手能吃掉你 3 子** / 其实下在 E4 可以提掉对方 1 子
- **记住棋盘大小**：下次打开自动沿用上次选的路数（存在浏览器本地，不上传任何数据）
- **完整规则**：提子、禁自杀、打劫全部正确实现
- **终局数子**：自动数子并弹出胜负（含 6.5 目贴目）
- **点目**：随时点击「点目」查看当前估算目数，棋盘上用黑白点标出双方地域；中盘仅供参考，死子需要先提掉
- **电脑自动认输**：后半盘电脑判断自己明显落后且局面已基本定型时，会主动认输，不再无谓长考
- **计时**：棋盘边显示总用时和每一手的历史耗时，右侧卡片显示本手、上一步和总用时

### 死活题
- 16 道**吃子题**，从「一口气」到「三手追杀」逐步加深
- **可交互**：点棋盘落子，电脑会自动走出白棋最顽强的应手
- 走错会立刻提示「白棋跑掉了」；走对有进度记录
- 全部做完会弹出「🏆 全部完成」，可以一键重来

### 打谱
- **载入自己的 SGF 棋谱**（点选文件或直接拖进来）
- 播放控制：`|◀ ◀ ▶ ▶ ▶|`，慢 / 中 / 快三档自动播放
- 手数列表可点击跳转，棋盘上红点标出最后一手
- 支持变化图（自动走主线）、`AB`/`AW` 摆子、虚手

### 入门教程
- 10 章图文教程，19 张自动生成的棋盘示意图
- 从「气」讲起，到做眼、吃子技巧、打劫、布局、数子
- 最后一章是「陪娃学棋的 10 条建议」

## 本地使用

直接双击 `index.html` 即可，**所有功能都能离线运行**（没有网络请求、没有外部依赖）。

如果想用本地服务器打开：

```bash
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

## 部署到 GitHub Pages

```bash
git init
git add .
git commit -m "围棋练习盘"
git branch -M main
git remote add origin https://github.com/<你的用户名>/<仓库名>.git
git push -u origin main
```

推送后，在仓库页面进入 **Settings → Pages**：

- **Source** 选 `Deploy from a branch`
- **Branch** 选 `main`，目录选 `/ (root)`
- 保存，等 1 分钟左右

访问地址：`https://<你的用户名>.github.io/<仓库名>/`

## 修改译文

| 文件 | 内容 |
|---|---|
| `i18n/core.js` | 基础设施（翻译函数、DOM 替换、语言切换） |
| `i18n/board.js` | 对弈页词条 |
| `i18n/practice.js` | 死活题 / 打谱页词条 |
| `i18n/tutorial-text.py` | 教程页 124 个段落的译文 |
| `i18n/extra.js` | 页面标题等零散词条 |

改完执行：

```bash
python3 i18n/build.py     # 重建 i18n.js
python3 i18n/verify.py    # 检查有没有漏翻的中文
git add -A && git commit -m "更新译文" && git push
```

`i18n/verify.py` 会按 JS 里完全相同的遍历逻辑静态模拟一遍，报告没被翻译的中文。需要先跑一次 `node i18n/dump-keys.js` 导出词条清单。

## 技术说明

- 纯 HTML + CSS + 原生 JavaScript，**单文件应用**，无构建步骤
- 棋盘用 Canvas 绘制，自适应窗口大小与手机屏幕
- **对弈 AI**：棋理启发式评分（提子 / 逃打吃 / 连接 / 边线价值 / 眼位）+ 一手风险评估 + 蒙特卡洛搜索（在候选池内做全局推演，拦截大漏着）
- **死活题求解器**：带记忆化和节点上限的深度优先搜索，用于判定「黑方能否必吃到白棋」，题目由程序生成并用它筛选、验证
- 所有棋谱和题目数据都内嵌在页面里，无任何外部资源
